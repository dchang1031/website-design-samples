# Website Design Samples

A collection of website design exercises. Each folder is a standalone project.

## Exercises

| Exercise | Description |
|---|---|
| [tr-design-exercise](./tr-design-exercise) | TokenRouter homepage design options (Current + Options 1–3) |

## How to run an exercise

```bash
cd tr-design-exercise
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173/current.html`).
