TokenRouter is a unified API gateway for accessing leading AI models across text, image, video, and audio.

Instead of integrating with multiple model providers one by one, developers and enterprises can connect through TokenRouter and manage model access through a single interface.

TokenRouter helps simplify model integration, centralize usage management, and provide a consistent way to access a broad range of AI capabilities.

TokenRouter helps teams reduce integration complexity by providing one unified API for multiple AI models and providers.

It also centralizes billing, usage tracking, and cost visibility. For enterprise users, TokenRouter supports organization-level analytics, usage reporting, budget visibility, and audit-friendly records.

To improve production reliability, TokenRouter supports multi-provider routing and fallback. When a provider becomes unavailable or unstable, TokenRouter can route requests to another available provider where supported, helping applications maintain better continuity.

Absolutely. TokenRouter adheres to strict Zero Data Retention (ZDR) policies. The platform only logs request metadata (like the model used, timestamp, and cost) and never stores your prompts or generated completions.

TokenRouter may retain limited operational metadata, such as request timestamps, model identifiers, token counts, latency metrics, account identifiers, billing records, IP addresses, and request headers, for routing, billing, security, fraud prevention, abuse prevention, analytics, support, and compliance. This metadata does not include the substantive content of your prompts or model responses.

When requests are routed to third-party model providers, provider-side data handling is governed by the applicable provider’s own terms, privacy policy, and technical configuration. Where available, PBD seeks to use providers and configurations with no-training, zero-data-retention, or equivalent privacy protections.

You can join the TokenRouter Discord community to ask questions, share feedback, or report technical issues.

You can also contact us directly through the Contact Us form on the TokenRouter website. For product questions, enterprise inquiries, billing issues, or bug reports, our team will help route your request to the right support channel.

TokenRouter displays pricing for each model. Depending on the model type and provider pricing structure, usage may be billed by input tokens, output tokens, cached tokens, requests, images, videos, audio, or reasoning tokens.

When you send a request through TokenRouter, the system calculates the applicable cost based on the selected model, provider, and actual usage. The corresponding amount is then deducted from your account balance.

You can review your request history, token consumption, model usage, cost details, and other billing-related information in Usage Logs.

TokenRouter continuously updates its model catalog to support newly released and widely used AI models across text, image, video, and audio.

We work with model providers and ecosystem partners to bring high-demand models online as quickly as possible. If there is a model you would like TokenRouter to support, you can contact us through Discord or the Contact Us form.

No, TokenRouter currently does not charge platform fees for using Personal or Enterprise software features.

Users can access the TokenRouter console, model catalog, API key management, Usage Logs, Dashboard, and enterprise management features without additional software subscription fees.

Model usage itself is still charged based on the selected model, provider, and actual consumption.

Yes. TokenRouter can support custom RPM and TPM limits for enterprise customers and high-volume use cases.

RPM means Requests Per Minute. TPM means Tokens Per Minute. Higher limits may depend on the selected models, provider capacity, usage patterns, commercial terms, and technical feasibility.

To request higher rate limits, please contact our business team through the Contact Us form.

TokenRouter is designed to support automatic fallback across available providers where applicable.

If a provider returns an error, becomes unavailable, or experiences instability, TokenRouter can route the request to another available provider for the same or compatible model, depending on routing configuration and provider availability.

This process is designed to be transparent to users and helps improve reliability for production applications.

TokenRouter primarily uses Stripe as its payment channel and uses US dollars as the base billing currency.

Prices shown on the website and through the API are generally denominated in USD. Users can top up their balance and use it to pay for model usage across supported models and providers.

TokenRouter does not charge users any payment processing fee for Stripe payments.
