# TokenRouter Design Exercise

Static design options for the [TokenRouter](https://www.tokenrouter.com/) homepage. Links are non-functional placeholders.

## Pages

- `/current.html` — Current (original TokenRouter homepage replica)
- `/` — Option 1
- `/option-2.html` — Option 2
- `/option-3.html` — Option 3
- `/option-4.html` — Option 4

Use the **Design Exercise** button in the top nav to open the hiring brief.
