# TokenRouter Design Exercise

Static design options for the [TokenRouter](https://www.tokenrouter.com/) homepage. Links are non-functional placeholders.

## Pages

- `/current.html` — Current (original TokenRouter homepage replica)
- `/` — Option 1
- `/option-2.html` — Option 2 (liquid motion + Scale-style expanding sections)
- `/option-3.html` — Option 3 (Global Route: world-map hero, giant type, sticky chapters)
- `/option-4.html` — Option 4 (Mono Grid: B/W light ultra-minimal clone of Option 3)

Use the **Design Exercise** button in the top nav to open the hiring brief.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
